# JavaFX-Projects
¡Bienvenido! Este repositorio reúne el catálogo de proyectos y soluciones de software de escritorio desarrollados con JavaFX, Scene Builder y MySQL.

## Tecnologías & Herramientas
- **Lenguaje:** Java (Java 17 / 21)
- **UI & Maquetación:** JavaFX, FXML, Scene Builder
- **Estilos:** JavaFX CSS (Diseño personalizado y Dark Mode)
- **Bases de Datos:** MySQL / SQLite
- **Arquitectura:** Patrón MVC (Modelo-Vista-Controlador)

## Proyectos Planificados / En Desarrollo

### 1. Sistema de Gestión / Dashboard JavaFX
- **Descripción:** Interfaz de usuario completa con menú lateral, tablas estilizadas, gráficos y filtros.
- **Estado:** *Planificado*

### 2. Formulario de Registro e Integración CRUD
- **Descripción:** Módulo de autenticación de usuarios y gestión de registros conectado a base de datos MySQL.
- **Estado:** *Planificado*

### 3. Plantillas de Componentes Reutilizables (UI Kit)
- **Descripción:** Colección de botones, modales y tarjetas estilizados en CSS para JavaFX.
- **Estado:** *Planificado*
